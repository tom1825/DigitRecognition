# DigitRecognition基于MNIST数据集的手写数字识别项目

## 一、项目简介
本项目基于MNIST手写数字数据集，使用Python和NumPy从底层手动构建神经元、网络层以及多层全连接神经网络，完整实现了前向传播、损失计算、反向传播和参数更新等核心过程，在不依赖PyTorch、TensorFlow等深度学习框架的前提下，完成手写数字分类任务。

为了进一步验证模型在复杂环境下的鲁棒性，在原始MNIST数据集的基础上，额外构造了带噪声数据集，通过加入`高斯噪声`和`随机遮挡`模拟真实场景中的图像干扰，并采用Adam优化器提升模型在噪声环境下的分类性能。

本项目包含“无噪声识别”和“带噪声识别”两个完整实验。

## 二、数据集

本项目使用经典公开数据集：[MNIST](chatgpt://generic-entity?number=0)

数据集基本信息：

- 样本总数：70000张
- 训练集：60000张
- 测试集：10000张
- 图像尺寸：28 × 28
- 输入维度：784维
- 分类类别：0~9，共10类

每张图像经过归一化处理：
```
X = X / 255.0
```
将像素值映射到[0,1]区间。

## 三、任务目标
主要完成以下两个任务：

### 任务一：无噪声手写数字识别
基于原始MNIST数据集，手动构建全连接神经网络，实现：
* 神经元设计
* 网络层设计
* 前向传播
* Softmax分类
* 交叉熵损失
* 反向传播
* 参数更新
要求模型测试集准确率达到95%以上。

### 任务二：带噪声手写数字识别
在原始MNIST图像基础上手动加入噪声，包括：
#### 1. 高斯噪声(x_noisy=x+noise,noise~N(0,σ²))
```
noise = np.random.normal(0, sigma, X.shape)
```
实验中设置：
* σ = 0.15
#### 2. 随机遮挡
在图像中随机生成小方块区域，并将像素值置0。

要求模型在带噪声测试集上准确率仍达到95%以上。

## 四、处理流程

### (一)数据预处理

* 数据下载
* 数据归一化
* 数据划分
* 噪声构造

### (二)模型搭建

手动实现以下模块：
#### (1)Linear全连接层(实现线性变换，y=xW+b)
* 权重初始化
* 偏置初始化
* 梯度计算

#### (2)ReLU激活函数
* 引入非线性

#### (3)Softmax输出层
* 将输出转换为概率分布

#### (4)BatchNorm(仅noise版本)
* 对每层输出进行便准化，提高训练稳定性。

#### (5)Dropout(仅noise版本)
* 训练阶段随机屏蔽部分神经元，降低过拟合风险。

### (三)模型训练

#### 无噪声
采用：
* Mini-Batch训练
* SGD参数更新
* 固定学习率

#### 带噪声
采用：
* Mini-Batch训练
* Adam优化器(自适应调节每个参数的步长)
* 余弦退火学习率
* BatchNorm(便准化每一层的输入)
* Dropout(随机屏蔽神经元)

### 模型测试
内容包括：
* 分类准确率
* 混淆矩阵

## 七、核心结论

本项目从底层手动实现了完整的全连接神经网络训练流程，并在MNIST数据集上成功完成了手写数字识别任务。
通过原始数据实验验证了模型的基本分类能力；通过带噪声实验进一步验证了模型在复杂环境下的鲁棒性。

### 结果表明：
* 手动实现的全连接神经网络能够有效完成图像分类任务；
* ReLU、BatchNorm和Dropout能够有效提升模型训练稳定性；
* Adam优化器能够显著提升带噪声环境下的收敛速度和分类性能；
* 模型在无噪声和带噪声条件下均达到95%以上分类准确率。
